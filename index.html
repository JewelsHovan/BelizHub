Your lectures stay
on your laptop.

This website hosts public learning tools. Your Lecture Desk is a separate local app: no account, cloud uploads, or AI processing in this first version.

Use only materials you have permission to record and process. You decide what to keep, export, or delete.

Set up your local Lecture Desk
  1. Get the BelizHub project and install Python 3.10 or newer, if needed.
  2. In a terminal, open the project folder and run: 
    python3 lecture-desk/server.py
    Keep that terminal open while studying. On macOS, you can also double-click Start Lecture Desk.command.
  3. Open Lecture Desk, try the sample, then add a TXT, SRT, or VTT transcript. Attach audio and PDF slides when you need them.

Already set up? Run the same command next time. Your place and notes will still be there. See the local app guide for backups and the offline RT-PCR build.
