One-time setup

Bring the visual lab onto this laptop.

The RT-PCR lab needs its own build. In a terminal, open the BelizHub project folder and run: 

cd pcr-explained
npm ci
npm run build

This requires Node.js 22 and an internet connection for the initial install. Reload this page after the build.
